# DoNex Video Editor (DN)

Free video editor for Android: no ads, no watermark.
Kotlin + Jetpack Compose, light and dark themes.

## Structure
- `ui/theme`: colors, shapes, typography (soft rounded "bubble" style)
- `ui/home`: home screen + Create Project sheet (Video / Shorts)
- `ui/editor`: editor screen (placeholder for now)
- `navigation`: app routes
- `model`: shared data types
